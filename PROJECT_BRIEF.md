# friedeggjellyfish — Project Background

## The gap

AI coding tools (Claude Code, Cursor, Copilot, agents) are great at writing automation scripts. But the resulting code has no visual layer — unlike n8n or Make.com, you can't see the flow, watch steps execute, or spot where things failed without digging into logs.

`friedeggjellyfish` is the missing visual layer. Drop it into any Python automation, run the dashboard, and watch your workflow execute step by step in real time.

## Who it's for

- Non-technical users who build automations with AI tools and want a visual view of what's running
- Solo developers and freelancers shipping automations to clients who need a simple "watch it work" view
- Anyone who's moved from n8n/Make.com to code-based automation and misses the visual workflow

## What it isn't

- Not a code builder — your AI assistant or you write the automation; FEJ just monitors it
- Not an n8n/Make.com replacement — different layer, different purpose
- Not a hosted SaaS — runs entirely on your machine, no cloud dependency
- Not Claude-Code-specific — works with any Python automation regardless of how it was written

## Why "Fried Egg Jellyfish"

The Fried Egg Jellyfish (*Cotylorhiza tuberculata*) is a Mediterranean species with a vivid golden center, tentacles in all directions, and a sting so mild humans barely notice it. It maps neatly to what the library does: lightweight, multi-step, visually striking, non-intrusive.

Nah, Kenneth just thought it was a good name 🤷
